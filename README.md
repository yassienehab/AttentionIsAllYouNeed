# AttentionIsAllYouNeed
This notebook builds a basic Encoder-Decoder variant of the Transformer architecture from scratch (Multi-Head Attention, Scaled Dot-Product Attention and Causal Masking included) in TensorFlow.  It serves to understand how each part of the Transformer works and how they all fit together. Translating sentences from English to French.


Steps :

1- Preparing the data

2- Building the Transformer

3- Training the Transformer

4- Testing the Transformer
